# Neopress Workspace Engineering Rules (`AGENTS.md`)

## Mission
Neopress is a drop-in WordPress CMS replacement written in native Rust (`Axum` + `Rusqlite`). Our primary objective is enabling **70%+ of active WordPress websites** (Elementor, Divi, Gutenberg, and Classic themes) to migrate in **1 click** and render an **exact visual and functional copy** with sub-millisecond latency.

## Core Engineering Mandates

1. **Zero Mock / Zero Toast-Only Handlers**:
   - Every Admin Portal screen (`/n-admin/*`) and REST API route (`/wp-json/wp/v2/*` and `/wp-json/neopress/v1/*`) MUST persist to and read from SQLite (`db.rs`).
   - Client-side `showToast(...)` handlers that do not make network requests to persist state are strictly forbidden.

2. **Zero Runtime Panics & Safe UTF-8 Handling**:
   - Never slice strings by raw byte index (`&s[..140]`); always use `.chars().take(N)` or `char_indices()`.
   - Never expose raw `.unwrap()` on user-controlled input, file paths, or optional database rows in HTTP request handlers.

3. **Relational Integrity in 1-Click & WXR Migrations**:
   - Both `db.rs::import_bundle` (`/wp-json/neopress/v1/import`) and `wxr.rs::import_wxr_xml` (`/wp-json/neopress/v1/import-wxr`) MUST maintain deterministic `old_post_id -> new_post_id` and `old_term_id -> new_term_id` mappings (or preserve original IDs) so `post_parent`, `page_on_front`, `page_for_posts`, `_thumbnail_id`, `categories`, `tags`, `nav_menu_item`, and `comments` never break.
   - Always run `neopress_ast::transpile_content` (with `ElementorKit` global styles when present) during both JSON bundle imports and WXR imports.

4. **Unified Layout AST Schema (`crates/neopress-ast`)**:
   - `NeopressLayout`, `StyleProperties`, and `NodeKind` in `crates/neopress-ast/src/schema.rs` MUST seamlessly deserialize and serialize both nested AST style objects AND flat Visual Builder style objects (`background_color`, `text_color`, `padding_top`, etc.) as well as all Visual Builder `NodeKind` variants (`Root`, `Column`, `NativeForm`, `Benchmark`, `Image`, `Icon`, `Counter`, `Spacer`, `Accordion`, `Tabs`, `Video`, `Form`).
   - Public SSR must never leak editor-only DOM attributes (`contenteditable="true"`, `.elementor-grid-handle`).

5. **Golden Master PHP-to-Rust Verification Loop**:
   - Any WordPress core PHP function or class transpiled to Rust (`crates/generated_*`) MUST be verified against a Golden Master JSON fixture generated by executing the actual PHP code (`php` or `docker exec neopress-ref-wp php`) via `generate_golden_master.php` and `neopress-transpiler`.
   - Raw `.php` files must never be placed inside `crates/neopress-server/static/`; store reference PHP fixtures in `fixtures/`.
