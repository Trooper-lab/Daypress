# Archetype 3: Elementor Starter Site Fixture

## Overview
This fixture exercises:
- `elementor_kit` settings and global kit CSS variable extraction (`--e-global-color-primary`, `--e-content-width`)
- Dual-write options persistence in SQLite
- Theme Builder header and footer templates (`np-elementor-header`, `np-elementor-footer`)
- Flexbox and container layouts
- Pro widgets (PriceCard, Countdown, CTA)
- Internal URL and media remapping (`source_site_url -> /` and `/wp-content/uploads/ -> /uploads/`)
- External links preservation (e.g. GitHub, external CDNs)
