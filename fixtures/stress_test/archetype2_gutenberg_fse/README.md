# Archetype 2: Gutenberg Full Site Editing (Twenty Twenty-Four)

## Overview
This fixture exercises:
- `theme.json` v3 schema parsing and compilation to CSS custom properties (`--wp--preset--color--*`, `--wp--preset--font-size--*`, `--wp--preset--spacing--*`)
- FSE HTML block templates (`templates/index.html`)
- FSE template parts (`parts/header.html`, `parts/footer.html`)
- Preset utility classes (`.has-primary-color`, `.has-secondary-color`, `.has-medium-font-size`)
- In-process and SSR verification without comment leakage
